# 🌟 My Local Escape 🌟
My Local Escape is a web application designed to provide users with a comprehensive guide to the city of Montpellier, including its gastronomy, visit options, and evening events. The project aims to help users plan their itinerary and make the most of their visit to the city. The application features a user-friendly interface, responsive design, and easy navigation, making it accessible to users of all ages and devices.

## 🚀 Key Features
- **Introduction to Montpellier**: The application provides an introduction to the city, including its history, culture, and attractions.
- **Gastronomy**: The application features a section on gastronomy, including articles on local cuisine, restaurants, and bars.
- **Visit Options**: The application includes a section on visit options, including articles on museums, landmarks, and outdoor activities.
- **Evening Events**: The application features a section on evening events, including articles on concerts, festivals, and nightlife.
- **Responsive Design**: The application is designed to be responsive, making it accessible on all devices, including desktops, laptops, tablets, and mobile phones.
- **Easy Navigation**: The application features easy navigation, including a navigation menu and anchor links to specific sections.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Google Fonts (Inter and Playfair Display), Custom CSS files (reset.css, variable.css, style.css, mobile.css)
- **Responsive Design**: Media queries, Flexbox, Grid
- **Build Tools**: None

## 📦 Installation
To install the application, follow these steps:
1. Clone the repository using `git clone https://github.com/username/repository.git`
2. Open the `index.html` file in a web browser to view the application

## 💻 Usage
To use the application, simply open the `index.html` file in a web browser and navigate through the different sections using the navigation menu and anchor links.
